
# Scripts

## adc_logger.py

Script for saving ADC test data. Measurements are read from the console and pushed to a .csv file for analysis. 

## adc_plotter.py

Main script for oscilloscope testing. Displays voltage waveform read from ADC in a separate window, along with basic measurements (Mean voltage, RMS voltage, Amplitude, etc). 

## data_gen.py

Initial prototype for adc_plotter.py. Generates a waveform with numpy rather than reading actual data.
